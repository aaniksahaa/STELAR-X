#  STELAR-X  —  Installation & Usage Quick Reference
###############################################################################
#
#  There are TWO ways to get STELAR-X running, depending on your needs.
#
# ─────────────────────────────────────────────────────────────────────────────
#  OPTION A:  Full Development Install  (edit code, rebuild, experiment)
# ─────────────────────────────────────────────────────────────────────────────
#
#  Prerequisites: Java 11+ (JDK), and optionally CUDA toolkit (for GPU)
#  (Maven is NOT needed — the bundled Maven Wrapper handles it automatically)
#
#  1. Clone the repo
       git clone <repo-url> && cd STELAR-X
#
#  2. Build everything (one command)
       ./install.sh                     # auto-detects CUDA; builds JAR + CUDA lib
       ./install.sh --no-cuda           # skip CUDA (CPU-only)
       ./install.sh --clean             # clean rebuild from scratch
#
#  3. Run
       ./run.sh -i <gene_trees.tre> -o <output.tre>                 # default (GPU if available, else CPU)
       ./run.sh -i <gene_trees.tre> -o <output.tre> --cpu-parallel  # force CPU parallel
       ./run.sh -i <gene_trees.tre> -o <output.tre> --gpu -e        # GPU + expansion
       ./run.sh -i <gene_trees.tre> -c <species.tre>                # score-only mode
#
#  4. Run with monitoring (time, memory, GPU stats)
       ./run-with-monitor.sh -i <gene_trees.tre> -o <output.tre>
#
#  After editing code, just re-run:
       ./install.sh                     # rebuilds everything
#
# ─────────────────────────────────────────────────────────────────────────────
#  OPTION B:  Precompiled Release  (just use it, no source code needed)
# ─────────────────────────────────────────────────────────────────────────────
#
#  Prerequisites: Java 11+ only. Nothing else.
#
#  1. Download and extract the release archive
       tar xzf stelar-x-1.0.0.tar.gz
#
#  2. Run (that's it!)
       ./stelar-x-1.0.0/stelar-x -i <gene_trees.tre> -o <output.tre>
       ./stelar-x-1.0.0/stelar-x -i <gene_trees.tre> -o <output.tre> --cpu-parallel
       ./stelar-x-1.0.0/stelar-x --help
#
#  Optional — add to PATH so you can run it from anywhere:
       sudo ln -sf $(pwd)/stelar-x-1.0.0/stelar-x /usr/local/bin/stelar-x
       stelar-x -i genes.tre -o out.tre
#
#  To build the release archive yourself (from the development install):
       ./dist.sh                        # produces dist/stelar-x-1.0.0.tar.gz (~3.3 MB)
       ./dist.sh --skip-build           # package existing build without rebuilding
#
###############################################################################
